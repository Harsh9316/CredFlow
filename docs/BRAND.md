## The mark

The mark is a **C bent from a curved rail track**: two rails with sleepers between them. It stands for credit decisions that run on dependable rails: consistent, explainable and auditable.

The name is written **Credrail** in text. The logo's wordmark is lowercase **credrail**, set in Inter SemiBold with tight tracking (−3.5%) and converted to outlines.

## Files

All files are in [`public/brand`](../public/brand) and are generated by `npm run brand:build` (`scripts/build-brand.mjs`).

| File | Use |
|---|---|
| `credrail-logo.svg` | Primary logo (mark + wordmark) on light backgrounds |
| `credrail-logo-dark.svg` | Logo on dark backgrounds |
| `credrail-mark.svg` | Mark alone, indigo |
| `credrail-mark-white.svg` | Mark alone, white (on indigo or photos) |
| `credrail-icon.svg` | App icon: white small-size mark on an indigo rounded square. Also the favicon (`app/icon.svg`) |
| `credrail-wordmark.svg` | Wordmark alone |

The Apple touch icon (`app/apple-icon.tsx`) and the link-preview image (`app/opengraph-image.tsx`, 1280×640) are rendered by Next.js. The same preview image is saved as [`docs/assets/social-preview.png`](assets/social-preview.png) for the GitHub repository's social preview.

## Small sizes

Below about 24px, the full mark's five sleepers merge, and a bare C with lines inside starts to look like © or €. At small sizes, always use the **app icon** (`credrail-icon.svg`). It uses a heavier small-size mark with two sleepers, framed by the indigo square.

## Colour

| Token | Hex | Use |
|---|---|---|
| Indigo | `#4F46E5` | Primary brand colour, app icon background, mark on light |
| Indigo (dark mode) | `#8B88FF` | Mark on dark backgrounds |
| Ink | `#101828` | Wordmark on light |
| Night | `#0F1222` | Dark brand background |
| White | `#FFFFFF` | Wordmark on dark, mark on indigo |

## Do and don't

- **Do** keep clear space around the logo equal to the height of one rail gap (about a quarter of the mark's height).
- **Do** use the dark-background version on anything darker than mid-grey.
- **Don't** recolour the mark outside the palette above, add effects, or rotate it.
- **Don't** set the wordmark in another typeface, or capitalise it in the logo.
- **Don't** use the bare mark below 24px; use the app icon instead.
